AI Blood Pressure Stage Predictor

📌 About the Project

AI Blood Pressure Stage Predictor is a web-based project designed to predict the blood pressure stage based on user-provided health parameters.

The project provides a simple and user-friendly interface where users can enter their required values and receive a predicted blood pressure stage.

«Note: This project is for educational and demonstration purposes only and should not be used as a medical diagnosis or replacement for professional medical advice.»

🎯 Objectives

- Predict the blood pressure stage based on user input.
- Provide a simple and easy-to-use web interface.
- Demonstrate the application of AI/ML concepts in a healthcare-related project.

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Enter the required values.
5. Click the prediction button.
6. View the predicted blood pressure stage.
